
# GEMINI.md

## Project Overview

This project, `chatgpt.js`, is a powerful client-side JavaScript library for interacting with the ChatGPT DOM. It is feature-rich, object-oriented, and easy-to-use, allowing developers to easily extend the functionality of the ChatGPT website. The library is written in JavaScript and is available as an npm package.

The core of the library is in the `chatgpt.js` file, which contains a large number of functions for interacting with the ChatGPT website. These functions include sending messages, getting responses, managing conversations, and much more. The `toolbar.js` file provides an example of how the library can be used to create a custom toolbar for the ChatGPT interface.

## Building and Running

### Building the project

The project can be built using the following command:

```bash
npm run build:js
```

This will create a minified version of the library in the `dist` directory.

### Running the project

The project is a client-side library, so it is meant to be used in a browser. The `README.md` file provides instructions on how to import the library into a project.

## Development Conventions

### Linting

The project uses ESLint for linting. The following commands can be used to run the linter:

*   `npm run lint`: Run the linter and show any errors.
*   `npm run lint:fix`: Run the linter and automatically fix any errors.

### Testing

There are no explicit tests in the project. However, the `toolbar.js` file can be used as a manual test to ensure that the library is working correctly.

### Contribution Guidelines

The `README.md` file provides instructions on how to contribute to the project. Contributions are welcome in the form of issues and pull requests.
